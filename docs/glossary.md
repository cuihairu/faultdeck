# Glossary

[中文术语表](/zh/glossary)。 These terms describe the implemented responsibility layers, not directory names. Architecture sections are in [Architecture](/architecture#source-layer-map).

| 术语 | English | 定义 | file:line |
|---|---|---|---|
| 故障规格 | `FaultSpec` | A tagged model for latency, loss, or disconnect semantics shared by the user boundary, coordinator, agent, and adapters. | `crates/core/src/lib.rs:26` |
| 故障目标 | `Target` | The optional IPv4 source, destination, and destination-port selectors that scope one injection. | `crates/core/src/lib.rs:44` |
| 注入请求 | `Injection` | One fault plus one target; this pair is the shared execution contract. | `crates/core/src/lib.rs:82` |
| 内在校验 | intrinsic validation | Checks fault ranges, non-empty targets, and IPv6 support before backend-specific behavior runs. | `crates/core/src/lib.rs:108` |
| 管理网段保护 | management-network protection | Rejects a target whose networks overlap operator-provided protected CIDRs. | `crates/core/src/lib.rs:142` |
| 执行器端口 | `CommandExecutor` | The netem adapter's boundary for running or recording `tc` commands; production and test executors implement it. | `crates/netem/src/lib.rs:73` |
| tc 命令 | `TcCommand` | A reproducible program-and-arguments representation of one traffic-control operation. | `crates/netem/src/lib.rs:56` |
| netem 适配器 | `NetemAdapter` | Plans, applies, and rolls back qdisc/filter state for latency and loss on one interface. | `crates/netem/src/lib.rs:172` |
| pilot qdisc | pilot qdisc | FaultDeck-owned root qdisc handle `100:` used to recognize and safely remove only its own traffic-control state. | `crates/netem/src/lib.rs:13` |
| 断连路由 | disconnect routing | The agent routes a disconnect injection to iptables instead of `tc`; other faults go to netem. | `crates/agent/src/lib.rs:196` |
| iptables 链 | iptables chain | The `FAULTDECK` mangle chain and its `INPUT` jump carry disconnect DROP rules. | `crates/agent/src/firewall.rs:9` |
| 断连适配器 | disconnect adapter | `Iptables` ensures the chain, installs DROP rules, and performs idempotent rollback. | `crates/agent/src/firewall.rs:31` |
| Agent 配置 | `AgentConfig` | Process-start settings: bind address, optional token, target interface, and management networks. | `crates/agent/src/lib.rs:90` |
| 单活动故障 | single active fault | Agent-host state that rejects a second injection until rollback clears the adapter marker. | `crates/agent/src/lib.rs:191` |
| Agent 线请求 | agent wire request | The tagged `ping`, `inject`, or `rollback` payload decoded by the agent host. | `crates/agent/src/lib.rs:109` |
| Agent 线响应 | agent wire response | The tagged `ok` or `error` result returned to the CLI. | `crates/agent/src/lib.rs:117` |
| 令牌鉴权 | token authentication | Optional shared-secret comparison at each process boundary; an unset token means auth is disabled. | `crates/agent/src/lib.rs:124` |
| NDJSON 帧 | NDJSON frame | A newline-delimited JSON value with a hard 64 KiB frame ceiling. | `crates/agent/src/transport.rs:56` |
| Mode A | Mode A | Agent-listens topology: the controller opens one TCP stream to the resident target agent. | `crates/agent/src/transport.rs:94` |
| Mode B | Mode B | Controller-listens reverse-connect topology with retry and backoff for NAT traversal. | `crates/agent/src/transport.rs:118` |
| 中枢信封 | `WireMessage` | The coordinator envelope carrying an optional token and one control command. | `crates/coordinator/src/lib.rs:98` |
| 中枢命令 | `AgentCommand` | Register, heartbeat, inject, rollback, fetch-report, or list-agents operations accepted by the coordinator. | `crates/coordinator/src/lib.rs:44` |
| 中枢响应 | `AgentResponse` | Coordinator acknowledgement, registry listing, report, or error result. | `crates/coordinator/src/lib.rs:55` |
| Agent 身份 | `AgentIdentity` | An agent ID, capability list, and last-seen timestamp stored by the coordinator. | `crates/coordinator/src/lib.rs:32` |
| 心跳 | heartbeat | Updates one registered agent's `last_seen_ms`; it does not currently compute online/offline status. | `crates/coordinator/src/lib.rs:77` |
| 中枢路由表 | coordinator routes | A logical agent-route map in coordinator state; its dispatch behavior is not wired. | `crates/coordinator/src/lib.rs:65` |
| 排队注入 | queued inject | Validates the injection, archives a report stub, and answers queued; it does not forward a command to an agent. | `crates/coordinator/src/lib.rs:159` |
| 场景 | `Scenario` | A named injection whose stable serialization is the input to hashing and reporting. | `crates/report/src/lib.rs:38` |
| 场景哈希 | scenario hash | The SHA-256 identity of a scenario, used for report lookup and comparison. | `crates/report/src/lib.rs:49` |
| 运行报告 | `RunReport` | The canonical result model containing scenario identity, timestamps, evidence, and replay text. | `crates/report/src/lib.rs:78` |
| 回放命令 | replay command | A shell-quoted CLI invocation generated by the user boundary and stored in the report. | `crates/cli/src/main.rs:206` |
| 恢复证据 | restore evidence | A timestamped post-rollback check with pass/fail and detail fields. | `crates/report/src/lib.rs:63` |
| 外部断言 | external assertion | A named externally observed result attached to a run report. | `crates/report/src/lib.rs:71` |
| 历史 diff | historical diff | A structural comparison of two reports' event, evidence, and assertion collections. | `crates/report/src/lib.rs:175` |
